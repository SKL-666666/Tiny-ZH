# Tiny-ZH v2-32M 训练

> 2026-11-16 启动 | **进行中** | 目标 ≥43/105

用正确数据配比重做 32M，验证「数据质量 > 参数数量」。

---

## 为什么做这个

v1-64M 的 42 分输给 minimind-3 的 70.5 分，归因已确认：**不是 token 少，是数据碎片化。**

本次要验证：**用一半参数 + 正确的数据，能不能追到 50-60 分。**

---

## 架构（33,367,552 参数）

```python
vocab_size=6400, hidden_size=512, num_layers=9,
num_heads=8, num_kv_heads=4, head_dim=64,
intermediate_size=1664,       # FFN/hidden = 3.25（v1 是 2.80）
max_position_embeddings=1024,
rope_theta=1000000.0,
tie_word_embeddings=True,
```

**设计原则：minimind-3 等比缩小，不发明新结构。**

| 项 | minimind-3 | 本方案 | 倍数 |
|---|---|---|---|
| FFN/hidden | 3.17 | **3.25** | 1.03× |
| GQA | 8/4 | 8/4 | 相同 |
| rope_theta | 1e6 | 1e6 | 相同 |
| 层数 | 8 | 9 | +1（补偿变窄） |

## 数据（与 v1 的根本区别）

| 数据源 | v1-64M | **v2-32M** |
|---|---|---|
| LCCC | **55%**（46字碎片） | **0%** |
| FineWeb | **35%**（网页噪声） | **0%** |
| **pretrain_t2t** | **0%** ❌ | **60%** ✅ |
| SkyPile-150B | 0% | 30% |
| CCI3-HQ | 0% | 10% |

**实测质量：**

| 数据源 | 平均字 | 中文占比 | 合格率 |
|---|---|---|---|
| pretrain_t2t | 274 | 0.77 | 76% |
| SkyPile | **970** | **0.83** | **87%** |
| CCI3-HQ | 2253 | 0.85 | 61% |

## 训练配置

| 参数 | 值 | 依据 |
|---|---|---|
| seq_len | 768 | pretrain_t2t p90=482 字 ≈ 720 token |
| micro_batch | 32 | 33M 只需约 12GB |
| grad_accum | 2 | 有效 batch 64 |
| lr | 8e-4 | 小模型可用更高，**前 500 步要盯** |
| 目标 token | 6.67 亿（20×） | Chinchilla 标准 |
