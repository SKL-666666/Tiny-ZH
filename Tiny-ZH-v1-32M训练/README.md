## 架构

```python
hidden_size=512, num_layers=10, num_heads=8, num_kv_heads=2,
head_dim=64, intermediate_size=1408,   # FFN/hidden = 2.75
max_position_embeddings=512,           # 声明 512，实际只训了 256
rope_theta=10000.0,
```

---

## 核心问题

**格式 100% 正确，内容 70% 错。**

17 条失败里有：
- **5 条完全崩成英文**（`"Content: More familiarous, is interacting..."`）
- **4 条字符复读**（`"odounoyyyyyyyyyy..."`）
- 3 条自问自答循环

**上下文也坏了**：声明 512 但只训 256，超 255 token 就输出 EOS。用 YaRN 补救只能治标。

---

## 教训

1. **31.5M 只能学格式，学不了内容** —— 容量问题
2. **崩成英文是容量不足的信号**
3. **声明长度必须等于训练长度** —— 否则超长输入直接崩
