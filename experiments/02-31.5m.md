# E2.1 — Tiny-ZH-31.5M

> 2026-11-08 | 已交付 | 得分 8/105（7.6%）

---

## 目标

从零训练一个 32M 左右的中文对话模型。原始需求：

> 「找一个不超过 1B 的小模型，模仿 minimind，做一个 32M 左右的超小模型，我不要求任何智商，只要求它有基本的语义理解，能说语法正确的人话，只需中文。但是，我要自己训练，词表、训练库等都是自己找的。」

---

## 架构

```python
ModelConfig(
    vocab_size=6400, hidden_size=512, num_layers=10,
    num_heads=8, num_kv_heads=2, head_dim=64,
    intermediate_size=1408,        # FFN/hidden = 2.75
    max_position_embeddings=512,   # 声明 512，实际只训了 256
    rope_theta=10000.0,
)
# 31,468,032 参数
```

## 实测表现

### 强的部分：格式 100% 正确

给它任何「如何 X」「为什么 X」的问题，一定能写成编号列表 + 小标题 + 解释句。

### 弱的部分：内容约 70% 错

| 问题 | 回答 | 错在哪 |
|---|---|---|
| 《红楼梦》作者 | 西代作家东南南村 | 编的 |
| 介绍传统节日 | 每年有3,42年到5000岁的款国 | 纯幻觉 |
| 推荐小说 | 《百年孤独》是中国小说 | 常识错 |
| 解释互联网 | 整条英文伪词 | **崩了** |

### 21 题严格测试：8/105（7.6%）

**崩坏模式：**
- 17 条里 **5 条完全崩成英文**（`"Content: More familiarous, is interacting..."`）
- **4 条字符复读**（`"odounoyyyyyyyyyyyyyyyyyy..."`）
- 3 条自问自答循环

**仅 4 条勉强及格**：如何保持健康、讲讲春天、秋天描写、1+1（虽错但没崩）。

### 采样参数实测

| 配置 | 表面正确 | 真实情况 |
|---|---|---|
| temp 0.7 / rep 1.25 | 4/8 = 50% | 多数是蒙对的 |
| temp 0.3 / rep 1.15 | 2/8 = 25% | 更差 |
| temp 0.1 / rep 1.05 | 2/8 = 25% | 开始复读 |
| 贪心 | 2/8 = 25% | 严重复读 |

**降温没用，反而更差。**

## 上下文问题

`config.py` 声明 512，但训练只用了 256。超过 255 token 时模型立刻输出 EOS。

修复：`--rope-scaling yarn --rope-scale 2 --yarn-orig-ctx 256`

| 输入 token | 修复前 | 修复后（YaRN） |
|---|---|---|
| 255 | stop（84 tok） | stop（74 tok） |
| **277** | **stop（91 tok）** | **length（100 tok）** |
| 357 | stop（44 tok） | length（100 tok） |

**但 YaRN 治标不治本**——277 token 输出正常，324 开始编造，357 崩成英文。根因是模型没在长上下文上训练过。

---

## 结论

1. **31.5M 学会了「怎么说」而不是「说什么」。** 格式全对，内容全错。
2. **崩成英文是致命问题**，说明容量不足以同时维持语言和格式。
3. **FFN/hidden = 2.75 偏低**，但当时不知道这是问题。
4. 上下文必须原生训练，YaRN 只是掩盖症状。
