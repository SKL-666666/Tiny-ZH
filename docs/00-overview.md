> 从零训练中文小模型。不是微调别人的，是从随机初始化开始。

## 阶段一：Mao-LoRA（2026-11-06 ~ 11-07）

**目标**：让 1B 模型学会《毛泽东选集》文风。

**方法**：LoRA r=32, alpha=64, 只对 q/k/v/o_proj 适配。lr 2e-5, 2 epoch, 822 步。

**结果**：用字符 2-4 gram TF-IDF + 逻辑回归训风格判别器（5 折 CV 准确率 0.9913）：

| 对象 | 风格分 |
|---|---|
| 未微调基座 | 9.9 |
| 微调后 | **77.1** |
| 真人毛选 | 79.8 |

**达到真人的 97%。**

### 这一轮确立的核心判断

**1B + LoRA 改不了能力，但能改表达分布。**

| 任务 | 本质 | 结果 |
|---|---|---|
| 四轮数学推理 | 要求长出没有的能力 | **四轮全败** |
| 毛选文风 | 把已会的往某方向推 | **一次成功** |

**风格是分布特征，只要句法语气像就够了；推理是无中生有，1B 容量装不下。**

这条判断贯穿后面所有决策。

## 关键结论汇总

### 能力边界

| 参数 | 能做到 | 做不到 |
|---|---|---|
| 31.5M | 格式正确 | 任何事实、推理（**崩英文**） |
| 64M | 格式 + 少量常识 | 具体知识、推理 |
| 300M | + 一些常识 | 复杂推理 |
| 1B+ | 开始有可用知识 | 仍然大量幻觉 |

### 两条最重要的判断

**1. 判断任务能不能做：这需要模型「长出」新能力，还是只需要它「偏向」某个方向？**

- 偏向（文风、格式、语气）→ 小模型 + 微调可以
- 长出（推理、知识）→ 必须足够大的容量

**2. 64M 输给 minimind-3，根因是数据质量不是 token 数**

| 项 | 我们 64M | minimind-3 |
|---|---|---|
| token | 9.42 亿（更多） | 约 2.5 亿 |
| 数据 | LCCC 46 字碎片 | pretrain_t2t 274 字完整段落 |
| 时长 | 5.4 小时（更长） | 2 小时 |
| 得分 | 40.0% | **70.5%** |

**为凑 20× 用碎片填充，模型学不会长程连贯。指标不能凌驾于数据质量。**
