# 模型微调（数学）

> 2026-11-06 ~ 11-07 | **已完结**（数学全败，文风成功）

用 MiniCPM5-1B 做 LoRA。这个目录记录的是**微调路线**，与从零训练的三个目录性质不同。

---

## 两条线，两种结果

### 线一：数学微调 —— 四轮全败

| 轮次 | 做法 | 结果 |
|---|---|---|
| 1 | 数学题 SFT | 不提升 |
| 2 | 加 CoT | 不提升 |
| 3 | 加大数据量 | 最好情况是不损伤 |
| 4 | 换数据配比 | 仍失败 |

**原因：数学推理要求模型「长出」它没有的能力，1B 容量装不下。**

### 线二：毛选文风 —— 一次成功

| 项 | 值 |
|---|---|
| 基座 | MiniCPM5-1B |
| 方法 | LoRA，r=32, alpha=64 |
| 适配层 | q_proj / k_proj / v_proj / o_proj |
| lr | 2e-5，2 epoch，822 步 |
| 语料 | 《毛泽东选集》全四卷，76.5 万字 |
| 样本 | 1,645 条，67.3 万字 |
| 硬件 | 8 核 CPU，105 分钟 |

**评测**：字符 2-4 gram TF-IDF + 逻辑回归风格判别器（5 折 CV 准确率 0.9913）

| 对象 | 风格分 |
|---|---|
| 未微调基座 | 9.9 |
| **微调后** | **77.1** |
| 真人毛选 | 79.8 |

**达到真人的 97%。**

## 这个项目最核心的一条判断

**1B + LoRA 改不了能力，但能改表达分布。**

| 任务 | 本质 | 结果 |
|---|---|---|
| 数学推理 | 长出能力 | **四轮全败** |
| 毛选文风 | 往某方向推 | **一次成功** |

**风格是分布特征，只要句法语气像就够了；推理是无中生有，1B 装不下。**

这条判断贯穿了后面所有的从零训练决策。
